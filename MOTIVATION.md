In the age of software that gets bloatet, working as a single developer got more harder.

Big software companies have resouces for 100 developers, therefore software can only be maintained by a large ammount of developers.
While complex software is the way to go for a use one for everything approach, it also has a big implementation complexity.

C++ is a hated and loved language but it shines in it's design philosophy for architecture compatibility compared to features.

UnderC is a self contained library, able to be implemented by a single developer.

It enables disabling features for a broader compatibility layer.
